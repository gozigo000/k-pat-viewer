# K-PAT 뷰어

특허청 제출 파일(hlz, dta, fin, xlz)을 브라우저에서 바로 보는 뷰어입니다.

## 사용법

1. 이 리포의 GitHub Pages 주소를 Chrome이나 Edge로 엽니다.
2. 특허청 제출 파일을 창 아무 곳에나 끌어다 놓습니다.

파일은 브라우저 안에서만 읽고 서버로 보내지 않습니다. 한 번 연 뒤에는 인터넷 연결 없이도 동작합니다.
설정과 칠한 곳은 이 브라우저에만 저장됩니다.

## 알림

개인이 만든 비공식 도구로, 특허청(KIPO)과 관계가 없습니다.

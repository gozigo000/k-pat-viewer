# K-PAT 뷰어

특허청 제출 파일(hlz, dta, fin, xlz)을 브라우저에서 바로 보는 뷰어입니다.


https://github.com/user-attachments/assets/2c9a611e-03ff-4d7f-9ff5-7905ab91ec51


## 사용법

1. https://gozigo000.github.io/k-pat-viewer/ 를 Chrome이나 Edge로 엽니다.
2. 특허청 제출 파일을 창 아무 곳에나 끌어다 놓습니다.

## 알림

개인이 만든 비공식 도구로, 특허청(KIPO)과 관계가 없습니다.

파일은 어디로도 전송되지 않습니다. 모든 처리는 내 PC의 브라우저 안에서만 이루어집니다.\
따라서, 페이지가 열린 뒤에는 인터넷 연결이 끊겨도 동작합니다.\
설정, 하이라이트 색칠 등은 이 브라우저에만 저장됩니다.
